# 자립준비청년 맞춤형 금융 MBTI 통합 기획 명세서 (Antigravity Context Spec)

## 1. 프로젝트 개요
- **목적**: 자립준비청년의 첫 정착금/자립수당 관리 어려움을 해소하기 위해 4개 성향 진단 문항(16가지 MBTI) 및 3개 위기 감지 문항을 통해 맞춤형 금융상품과 정부지원정책을 추천.

## 2. 4대 진단 축 (Q1 ~ Q4)
1. **자산관리 (P vs F)**: P (계획형, 미리 세팅) vs F (자유형, 유연 조절)
2. **소비습관 (E vs V)**: E (가성비형, 최저가/실속) vs V (가치형, 취향/자기보상)
3. **정보탐색 (A vs R)**: A (직접서치형, 능동 검증) vs R (추천참고형, 기관/선배 추천)
4. **비상금운용 (S vs I)**: S (안전·유동성, 파킹통장/예적금) vs I (수익·투자, 주식/ETF)

## 3. 재정위기 조기발견 3문항 (Q5 ~ Q7) & 가중치
- **Q5 (지출 예산 소진)**: ①,②(0점 안심) / ③(1점 주의) / ④(3점 고위험)
- **Q6 (SNS 고수익 제안)**: ①(0점 안심) / ②,③(1점 주의) / ④(3점 고위험)
- **Q7 (채무/사기 고립도)**: ①(0점 안심) / ②(1점 주의) / ③(2점 주의) / ④(3점 고위험)

## 4. 위기 등급 판정 기준
| 등급 | 점수 범위 | 색상 | 의미 |
| :--- | :--- | :--- | :--- |
| GREEN | 0~1점 | 🟢 | 안심 — 건강한 재정 습관 유지 |
| YELLOW | 2~4점 | 🟡 | 주의 — 위험 감수 징후, 유의 필요 |
| RED | 5~9점 | 🔴 | 고위험 — 긴급 전담기관 상담 필요 |
